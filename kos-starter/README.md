# kos-starter — 个人工作知识库起步 skill

> 装好之后，对 AI 说一句「搭建知识库」，它会带你 30 分钟完成骨架与种子访谈（当天可用；含装工具首日全程约 1 小时），直接搭出「让 AI 一开门就认识你和你的工作」的完整工作知识库，并在后续使用中帮你入库记账、养护体检，长到 AI 分身。

## 双包说明

本仓库是**通用骨架包**：零组织内容，任何人可直接使用。团队/组织若有统一分发的**预置内容包**（文档模板、工作流说明等），走组织内部分发渠道另行获取——BUILD 时 skill 会问你要不要挂载，挂载后包内模板生效；没有预置包不影响任何功能。

## 你需要先有

一台电脑 + 任意一个 AI 编码工具（能对话、能读写本地文件）。在公司或组织的设备/网络使用前，先确认所在组织对外部 AI 工具的许可口径：

| 工具 | 获取方式 | 特点 |
|---|---|---|
| OpenCode | 开源免费，github.com/sst/opencode，按说明安装 | 免费全功能 |
| Cursor | 官网下载安装 | 图形界面，最好上手；搭库无碍（AGENTS.md Cursor 原生支持），skill 加载能力因版本而异未实测，首选 OpenCode / Claude Code |
| Claude Code | Anthropic 出品 | 需订阅 |

手机 / 平板暂不支持（skill 依赖读写本地文件的能力，先在电脑上搭）。

## 怎么装（2 分钟）

1. 获取 skill 文件夹（任选其一）：
   - 命令行：`git clone https://github.com/OYAlivn/skills.git`，取其中的 `kos-starter` 文件夹
   - 网页：GitHub 仓库页（OYAlivn/skills）Code → Download ZIP，解压后取 `kos-starter` 文件夹
2. 把整个 `kos-starter` 文件夹复制到你 AI 工具的 skills 目录：
   - Claude Code / OpenCode：`C:\Users\你的用户名\.claude\skills\`（macOS：`~/.claude/skills/`）
   - 其他工具：查其文档中「skills / 技能 / extensions」的安装位置，通常是类似的 skills 目录
3. 重启你的 AI 工具、开一个新会话（skills 在会话启动时加载）
4. 验证：问 AI「你现在有哪些 skill」，列表里出现 kos-starter 即成功（本 skill 实测通过：OpenCode、Claude Code）。个别工具不暴露 skill 列表——直接说「搭建知识库」，进入引导流程即成功

## 装完怎么说

| 你说 | 发生什么 |
|---|---|
| 「搭建知识库」（第一次） | 30 分钟完成骨架与种子访谈：四区结构 + 各级索引 + Git 一次到位，工作档案与风格三件套由访谈生成（你确认后才写入），有组织预置内容包可选挂载，收尾对账验收 |
| 「记录这个」+ 内容（日常） | AI 先过红线预拦，再报「四选一」分诊入库，自动登记索引 |
| 「体检」「养护」（库用了一阵后） | AI 跑对账脚本 + 内容级体检出报告；项目完结说「项目完结提炼」，换电脑说「迁移知识库」 |

## 不想装 skill？

把本仓库的 `kos-starter` 文件夹发给任意能读写本地文件的 AI，说「按 build-guide 带我搭知识库」——skill 文件本身就是完整的搭建说明书。

## 安全一句话

库文件只存在你的电脑上；但 AI 读库时，内容会随会话发送给它背后的模型服务商——**会话本身不保密**。红线内容（密码密钥、证件号码、薪酬信息、未公开合作条款等）不入库、不进会话；库推远程前，工作场景确认用的是组织认可载体，个人场景确认用的是私有仓库。
