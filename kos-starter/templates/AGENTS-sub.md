# AGENTS-sub — 子目录索引模板

> 用途：给 `work/{产品线}/` 与 `knowledge/` 两个内容分区配子目录索引。下方两个形态**择一**填充：替换全部 `{{占位符}}`，删掉用不上的行和本说明，只保留选中的形态作为该目录的 AGENTS.md。
> 说明：`style/` 为扁平风格文件，三个文件直接登记进根索引，不建子索引；`archive/` 终态冻结不套子索引（项目归档时保留原目录索引一并冻结）。

| 目录 | 用途 |
|---|---|
| `context/` | 已确认的产品知识（架构 / 功能 / 术语 / 项目档案） |
| `workspace/` | 进行中的版本需求、方案、会议纪要 |
| `drafts/` | 未成型的草稿与素材 |

## 规矩

1. Read 任何文件前先查本索引；未索引的文件不可见
2. 新文件在 Recent 区追加一行（日期 + 文件名 + 一句话），不改正文清单

4. 疑似红线内容不入库、不登记——先提醒我确认安全口径
